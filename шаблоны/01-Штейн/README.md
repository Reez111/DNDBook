# Шаблон 1 — Штейн

Визуальный ориентир: предоставленные пользователем изображения из Steinhardt's Guide to the Eldritch Hunt. Тёмный тёплый фон, серо-бежевый текст, приглушённое золото заголовков, две колонки, тёмные плашки, таблицы и крупные атмосферные изображения. Иллюстрации, орнаменты, силуэт города и текстуры подбираются отдельно для каждого проекта.

## Применение

1. Создайте документ в Homebrewery и выберите движок V3.
2. Содержимое файла `стиль.css` вставьте во вкладку Style.
3. Содержимое `пример.md` вставьте в редактор текста и замените своим материалом.
4. При необходимости добавьте свои изображения и вручную настройте расположение элементов под конкретные страницы.

Это первая версия шаблона: внешний вид и совместимость в редакторе ещё не проверены. Фон при печати может потребовать включения печати фоновой графики в настройках браузера.
