# Каталог шаблонов

1. **Штейн** — тёмное готическое фэнтези, по визуальным примерам пользователя. Файлы: `01-Штейн/`.

При создании нового шаблона добавлять отдельную папку с номером и названием и запись в этот каталог. Шаблон выбирается по названию или номеру. Сохранять описание стиля, CSS и пример разметки отдельно.
