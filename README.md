# Мастерская рукописей

Распакуй архив в папку. Для Windows установи Python 3.11 или 3.12 с Python Launcher и открой Запуск.bat. Для macOS/Linux из папки приложения выполни python3 -m venv .venv, затем .venv/bin/pip install -r requirements.txt и .venv/bin/streamlit run app.py --server.address=127.0.0.1. Для установки нужен интернет.

Текст можно вставить, загрузить как TXT/MD в UTF-8 или извлечь из PDF с текстовым слоем. Проверь порядок колонок после извлечения. Базовый режим сохраняет абзацы, отмечает заголовки и списки. В режиме ИИ рукопись отправляется в OpenAI по твоему API-ключу, оплата по тарифу API. Большие книги обрабатывай по главам. В Homebrewery V3 вставь рукопись.md в редактор текста, стиль.css во вкладку Style. Новые папки шаблонов со стиль.css и пример.md добавляй в каталог шаблоны.
